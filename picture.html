Image Format Support

Format MIME Type Browser Support Advantages
AVIF image/avif Chrome 85+, Firefox 93+, Safari 16+ Best compression, smallest files
WebP image/webp Chrome, Firefox, Edge, Safari 14+ Excellent compression, wide support
JPEG image/jpeg Universal support Universal fallback, good for photos
PNG image/png Universal support Transparency support, lossless
SVG image/svg+xml Universal support Scalable, small file size for graphics

Srcset Descriptors

  • Width descriptor (w): Tells the browser the actual width of the image file (e.g., image-800.jpg 800w)
  • Pixel density descriptor (x): Specifies the pixel density (e.g., image-2x.jpg 2x for retina displays)
  • sizes attribute: Tells the browser how much space the image will take up (used with width descriptors)

Best Practices

  • Always include an <img> tag as the fallback inside <picture>
  • Place the most specific source first and fallback last
  • Use modern formats (AVIF, WebP) with JPEG/PNG fallbacks for better performance
  • Provide multiple resolutions to optimize for different screen sizes
  • Always include descriptive alt text on the <img> element
  • Consider art direction - serve different crops or compositions for different viewports
  • Test across different browsers and devices
  • Use appropriate image compression to balance quality and file size
  • Combine media queries with type queries for maximum flexibility
  • Consider lazy loading for images below the fold (add loading="lazy" to img)

Common Use Cases

  • Responsive images: Serve different sized images for different screen widths
  • Art direction: Show different image compositions on mobile vs desktop
  • Format optimization: Serve modern formats to supporting browsers
  • Retina displays: Provide high-resolution images for high-DPI screens
  • Dark mode: Switch images based on user's color scheme preference
  • Orientation: Adapt images for landscape vs portrait orientation
