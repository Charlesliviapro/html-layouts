Video Format Compatibility

Format MIME Type Browser Support Notes
MP4 (H.264) video/mp4 Chrome, Firefox, Safari, Edge, IE9+ Most widely supported format
WebM (VP8/VP9) video/webm Chrome, Firefox, Opera, Edge Open source, good compression
Ogg (Theora) video/ogg Chrome, Firefox, Opera Open source, older format

Caption Track Formats (WebVTT)

WebVTT File Example (sample-en.vtt):

WEBVTT

00:00:00.000 --> 00:00:05.000
Welcome to our video tutorial.

00:00:05.000 --> 00:00:10.000
Today we'll learn about HTML5 video elements.

00:00:10.000 --> 00:00:15.000
Let's get started with the basics.

Note: WebVTT (Web Video Text Tracks) is the standard format for captions and subtitles.

Track Kind Types

  • subtitles: Translation of dialogue (for foreign language content)
  • captions: Transcription of dialogue and sound effects (for deaf/hard of hearing)
  • descriptions: Text descriptions of visual content (for blind/low vision users)
  • chapters: Chapter titles for navigation
  • metadata: Additional information not displayed to users

Best Practices

  • Always provide multiple video formats (MP4 and WebM minimum) for browser compatibility
  • Include a poster image to display before the video loads
  • Add caption tracks for accessibility (required by many accessibility standards)
  • Use the controls attribute to provide playback controls
  • Set appropriate width and height to prevent layout shifts
  • Use preload="metadata" for better performance
  • Provide fallback text for browsers that don't support video
  • Consider bandwidth - compress videos appropriately
  • Test captions across different browsers
  • Always include the default attribute on one track to ensure captions load automatically
